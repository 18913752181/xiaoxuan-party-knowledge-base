# 党员发展时间助手（微信小程序第一版）

第一版只提供“入党时间核算”：用户填写已经发生的阶段日期，小程序在本地计算阶段间隔、当前阶段、明显冲突、下一步工作和参考办理时间。

## 数据与边界

- 无需登录、免费使用。
- 用户填写的日期只保存在微信本地存储，不上传网站、接口或 Supabase。
- 小程序不判断政治条件、材料质量、会议程序或审批结果。
- 结果仅供工作参考，应以现行党内法规和上级党组织要求为准。
- 网站、接口、数据库和会员系统不属于本次改动范围。

## 页面

- `pages/index/index`：单一核心入口。
- `pages/calculator/calculator`：五个阶段日期填写页，除申请日期外均为选填。
- `pages/result/result`：核算结果、下一步提醒、注意事项、相关资料。
- `pages/webview/webview`：打开网站统一维护的专题、模板和常见问题。

旧资料库页面文件仍保留在目录中，但已从 `app.json` 移除，不会进入第一版小程序。

## 规则维护

所有业务规则集中在：

```text
config/time-rules.js
```

核算代码位于：

```text
utils/time-calculator.js
```

修改规则时：

1. 先核对现行党内法规和上级党组织要求。
2. 修改 `config/time-rules.js` 对应规则的时间值、说明、依据和是否自动判断。
3. 同步更新配置中的 `version`、`effectiveDate`、`reviewedAt`。
4. 为变化后的边界日期补充或修改 `tests/time-calculator.test.js`。
5. 运行 `node miniprogram/tests/time-calculator.test.js`。

当前自动判断规则：

- 收到入党申请书后一个月内谈话：由于未采集谈话日期，只显示截止参考日，不自动判超期。
- 申请后一般考察满半年确定积极分子：未满半年显示“需要核对”，不作绝对违规结论；具体制度依据待补充。
- 入党积极分子培养教育考察满一年后方可列为发展对象：未满一年标记异常。
- 预备党员预备期一年：未满一年转正标记异常；晚于满一年日期则提示结合实际办理情况核对。
- 周年按日历日期计算，例如 2026-01-01 的一年期满参考日为 2027-01-01。

## 网站专题跳转

网站地址和专题路径在 `config/time-rules.js` 的 `site` 与 `relatedResources` 中维护。小程序通过 `web-view` 打开：

```text
https://xiaoxuanvip.com/topics/development-members
```

正式发布前，必须在微信公众平台将 `xiaoxuanvip.com` 配置为小程序业务域名，并按平台要求在该域名根目录放置校验文件。

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本 `miniprogram/` 目录。
3. `project.config.json` 已配置正式 AppID `wxfa7b15cdbb16a761`；如复制为其他小程序项目，再替换为对应 AppID。
4. 点击“编译”，依次测试首页、日期填写和结果页。
5. 本地调试网站入口时，可在开发者工具“详情 → 本地设置”暂时勾选“不校验合法域名、web-view（业务域名）”。正式版不能依赖此设置。

## 提交审核前检查

1. 在微信公众平台完成小程序名称、类目、隐私保护指引和业务域名配置。
2. 使用正式 AppID，在真机上检查所有日期边界和网站入口。
3. 在开发者工具点击“上传”，填写版本号和项目备注。
4. 登录微信公众平台，在“版本管理”中选择开发版本并提交审核。
5. 审核说明中写清：本工具提供党务工作日期辅助核对，结果仅供参考，不替代党组织审查审批；第一版不收集、不上传用户填写的日期。
6. 审核通过后，在版本管理中发布。

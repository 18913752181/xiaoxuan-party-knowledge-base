
# 资料库年卡下载

- 网站购买页、套餐接口与两种微信下单接口只接受年卡。已创建的月卡、季卡订单仍按原时长履约，现有套餐有效期不变。
- 有效年卡可下载所有已发布且带附件的资料，可重复下载。已有资料下载权益的旧会员继续享有下载权限；其他月卡、季卡不新增下载权限。
- 单份、批量及会员中心使用同一服务端判断：有效期内的已付款年卡或存量下载权益。已退款的订单不可授权。访客可浏览资料说明，下载需先登录。权限查询失败时拒绝下载。
- ZIP 单批最多 50 份，原文件合计不超过 100 MB；可以分批打包，无每日限额。
- 停止发放、扣减和展示积分。订单、原余额、历史积分流水、下载及收藏记录全部保留。

## 发布顺序

1. 在生产 Supabase 执行 `supabase/049_unlimited_annual_material_downloads.sql`。该迁移可重复执行，保留旧版下载接口所需的兼容函数。
2. 用服务端权限核验 `material_download_entitlement` 和 `refund_membership_order` 已安装后，再推送生产分支。
3. 部署网站和提醒容器，核验会员购买页、套餐接口及两种下载接口。使用已授权测试账号验证：年卡下载、月卡拒绝、到期、退款、续费。勿在生产发起真实支付或退款作为测试。

## 本地检查

- `node scripts/test-material-access.cjs`：两种下载接口、授权失败、ZIP 限制、重复下载及套餐配置。
- `node scripts/test-unlimited-annual-downloads.cjs <PGlite 模块路径>`：依次执行 045 至 049 迁移，验证存量兼容、支付、续费、退款、到期、权限防篡改及余额保留。
- `npm run build`。

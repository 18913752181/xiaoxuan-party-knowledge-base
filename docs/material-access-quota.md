# 资料权限部署说明

普通会员累计可预览 5 份不同资料，同一份资料重复预览不重复计数。下载不消耗预览额度：普通资料可下载，会员专属资料仅付费会员可下载。付费会员有效期内全部可预览和下载，并可批量下载。付费预览不消耗普通额度，到期后恢复原有普通预览额度。

本次生产部署使用已有持久化挂载 `/srv/xiaoxuan/shared/data`（容器内 `/app/data`）保存 `material-access/` 额度记录，不依赖新的 Supabase SQL 函数。记录从功能上线后首次成功获取资料开始，不导入可编辑的旧下载历史。会员身份仍通过 Supabase profiles 及用户认证令牌验证。

每个账号一个散列文件名；目录锁串行化同账号的并发请求，写入先落临时文件、同步磁盘，再原子替换。预览解析失败、文件不存在不占额度。服务器准备好内容并记账后若连接断开，不退回名额，同一份可重试。

更新和重启必须保留现有 data 挂载，并将该目录纳入备份。多进程或同主机容器共享此挂载；未来扩展到不同主机时，必须先迁移额度记录至共享存储，不可为各节点新建独立额度目录。没有客户端清零接口。

程序异常退出可能留下账号 `.lock` 目录；为防止重复计数，程序不会擅自抢锁。维护时应先停止全部 web 实例，确认没有额度写入，再仅清理空的账号 `.lock` 目录；不得删除对应 JSON 记录。损坏记录和存储故障均拒绝授权，不会重置额度。

上线前运行：
- node scripts/test-material-quota.cjs（真实多进程并发、去重、重启和账号隔离）
- node scripts/test-material-access.cjs（权限接口和付费批量 ZIP）
- node scripts/test-material-preview.cjs（文件解析）
- npm run build

批量下载每批最多 50 份、原文件总计 100 MB。旧版或加密 Office 文件暂需下载查看。

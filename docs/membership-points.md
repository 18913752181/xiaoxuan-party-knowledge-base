# 会员积分发放规则

## 套餐

- 月卡：保持现价，支付成功后一次性赠送 5 积分。
- 季卡：保持现价，支付成功后一次性赠送 20 积分。
- 年卡：99 元/年，在年卡实际生效区间内每天赠送 10 积分。

套餐购买继续沿用现有微信支付、订单金额核验、会员顺延和退款流程。积分发放不改变资料预览、下载、批量下载或既有积分消耗逻辑。

## 幂等与补发

`point_transactions.idempotency_key` 是数据库唯一键。月卡和季卡使用订单 ID 生成赠送键；年卡使用用户 ID 与日期生成每日赠送键。因此重复支付回调、订单轮询自愈、页面刷新、容器重启和并发定时任务都不会重复增加余额。

定时容器每小时调用一次内部积分接口。数据库函数会枚举年卡周期中截至当天尚未写入流水的日期，所以服务短暂停机后会自动补齐漏发日期。会员到期、周期尚未开始或年卡订单已退款时不再发放。

## 存量兼容

- 历史订单金额、会员到期日和已有余额不修改。
- 历史月卡、季卡不追溯赠送开通积分。
- 存量有效年卡从迁移执行日开始每日赠送，不追溯迁移前日期。
- 每一笔仍有效的历史年卡按该订单的到期日建立年度积分周期；历史月卡、季卡不会被误判为年卡。
- 旧系统没有订单记录的有效会员按旧站原有年费会员处理。
- 退款只停止未来年度积分，已发积分不扣回。

## 上线顺序

1. 在 Supabase 执行 `supabase/045_membership_points.sql`。
2. 将生产环境 `DIMMO_ANNUAL_PRICE_CENTS` 更新为 `9900`。
3. 部署网站与 `reminder-dispatcher` 容器。
4. 调用一次 `/api/internal/membership-points/grant-daily`，确认返回的发放数量与积分流水一致。
